Temuan Utama

Data dalam Machine Learning terdiri dari fitur dan label. Fitur merupakan data atau atribut yang digunakan untuk membantu melakukan prediksi, sedangkan label merupakan hasil yang ingin diprediksi. Label dapat berupa kategori pada klasifikasi atau nilai numerik pada regresi. Selain itu, data dibagi menjadi data latih dan data uji untuk melihat kemampuan model dalam mengenali data yang belum pernah dilihat sebelumnya.
